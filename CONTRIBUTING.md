# Contributing to Lumen

This is an independent, noncommercial Linux adaptation, not an official NullMoth project. Retain original notices and component licenses. Contributions must be understood and reviewed by their submitter; disclose AI assistance and test results. Never include personal hardware reports, SMBIOS identities, credentials, downloaded driver packages or Apple recovery images.

Run `python -B -m unittest discover -s tests_linux -t . -v` before proposing changes. Physical USB work requires dedicated disposable media and explicit target confirmation.

The upstream 1401 project has its own policy prohibiting AI-written PRs, issues and review comments. Do not submit generated contributions there. Its policy is available at https://github.com/nullmoth/1401/blob/main/CONTRIBUTING.md .
